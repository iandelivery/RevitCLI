### Highlights

- **Skill installs default to user level.** `skill install` now registers `SKILL.md` under the user profile (`~\.claude`, `~\.trae`, ...), so a plain install no longer drops the skill into whatever folder the terminal happened to be in — previously it landed inside the current working directory, e.g. the extracted release-zip folder. Use `--project` to install at project level (current directory); it replaces the removed `--global` flag (passing `--global` is harmless and now behaves as the user-level default).
- **Local bridge builds stamp the real version.** `bridge\build.ps1` derives the semantic version from the latest reachable `v*` tag, so locally deployed bridge DLLs no longer report the stale placeholder version.
- **Better third-party plugin docs.** The bridge README documents programmatic registration via `BridgeRegistration`, the rule against shipping local `RevitCliBridge.Abstractions.dll` / `Newtonsoft.Json.dll` copies, and verifying discovery with `revit-cli catalog`.

Upgrade: replace your install folder, re-run `revit-cli.exe configure setup`, and refresh existing skill installs with `revit-cli.exe skill update`.
