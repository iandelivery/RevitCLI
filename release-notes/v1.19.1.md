### Highlights

- **`http://127.0.0.1:{port}` now works.** The bridge bound only the `localhost` prefix, so requests addressed to the raw loopback IP were rejected by HTTP.sys with 400 "Invalid Hostname" — indistinguishable from the bridge not being there, which sent a real troubleshooting session (2026-11-19) down the wrong path toward discovery and auth. The listener now registers both loopback prefixes; `localhost` keeps working unchanged, and nothing outside the loopback interface is bound.

Upgrade: replace your install folder (bridge side only — the client is unchanged in this release).
