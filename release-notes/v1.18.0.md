### Highlights

- **Retry-safe commands.** Pass `--request-id <id>` on any command and the bridge returns the existing task instead of running it a second time. Timed-out tasks now stay timed out permanently — previously a task that finished late after its timeout flipped back to `completed`, so an agent that retried could create an element twice.
- **Detached long tasks.** `--no-wait` submits a command, prints `task_id: <id>`, and exits 0 immediately; poll later with `revit-cli.exe task -ti <id>`. `--timeout <seconds>` raises the per-command budget (default 120) for long `batch_export` or `execute_raw` runs, and the `task_id` is also printed on the SSE `accepted` event so a killed process leaves its ID behind.
- **A real exit-code contract.** 0 success, 1 usage error, 2 bridge unreachable or auth rejected, 3 timed out, 4 command failed. stdout now carries the result JSON only; progress, `task_id`, and errors go to stderr, so `revit-cli.exe <command> 2>$null` yields parseable JSON.
- **Self-service discovery.** Dynamic commands answer `--help` with their schema (description, parameters, defaults, examples, offline via the schema cache). Unknown names get up to three "Did you mean" suggestions from the client and the bridge. `--dry-run` on an unsupported command is rejected locally instead of burning a bridge round trip.
- **`execute_raw --stdin`.** Pipe a C# script (`Get-Content script.cs -Raw | revit-cli.exe execute_raw --stdin`) instead of fighting shell quoting on Windows.
- **`resolved_failures` reporting.** When Revit auto-resolves model errors during a `create_walls` commit, the response carries a `resolved_failures` array so agents can tell a clean commit from a corrected one.
- **Configurable task retention.** `task_retention_seconds` in `cli_bridge_setting.json` (default 900) controls how long finished task results stay queryable; failed and timed-out tasks are kept for an hour and the task 404 response explains the window.

Upgrade: replace your install folder, re-run `revit-cli.exe configure setup`, and refresh existing skill installs with `revit-cli.exe skill update`.
