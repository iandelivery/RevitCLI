### Highlights

- **The units contract.** From 2.0 on, an agent never receives a Revit internal unit. Every dimensional argument and response value is expressed in the request unit of its kind — canonical `length=mm`, `area=m2`, `volume=m3`, `angle=deg` — and every response carries a `units` echo naming the units used. Choose per invocation: `--units length=ft --units angle=rad` (repeatable pairs) or `--units project` to follow the document's display units (`get_units` reports them). Outputs round to 3 decimals; inputs are never rounded.
- **`get_parameters` reports `unit_kind` per parameter** and reads/writes doubles in the request units — the parameter commands no longer leak bare internal feet.
- **Breaking renames.** Suffixed fields and parameters (`diameter_mm`, `width_mm`, `height_mm`, `offset_mm`, `length_mm`, `base_offset_mm`, `rotation_deg`, `overlap_area_mm2`, …) rename to unsuffixed names; the `units` echo replaces suffixes as the contract. Update parsers keyed on the old names or on raw feet.

Upgrade: replace the add-in folder (bridge side) and the `revit-cli.exe` client together. `execute_raw` scripts are unchanged. The Abstractions NuGet bumps in lockstep to 2.0.0.
